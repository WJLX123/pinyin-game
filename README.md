# 一年级拼音闯关游戏 Pinyin Adventure

面向一年级小朋友的拼音闯关游戏（单文件网页，可离线玩）。

## 玩法入口

- 在线玩：<https://WJLX123.github.io/pinyin-game/>
- 本地玩：直接用浏览器打开 `一年级拼音闯关游戏.html`

## 内容

- 覆盖一年级全部 63 个拼音：23 声母 + 24 韵母 + 16 整体认读音节，共 13 关
- 每个拼音配 2 个例字，每个字配 3 个含该字的四字成语
- 学习卡（顺口溜 + 点读）+ 闯关测验（拼一拼 / 选声母 / 选韵母 / 辨声调）+ 星级评价
- 进度自动保存在浏览器 localStorage

## 更新方法

修改 `一年级拼音闯关游戏.html` 后重新推送到本仓库（main 分支），GitHub Pages 会自动更新。
